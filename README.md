# Pornhub 客户端安装源

这是 [PornHubApp](https://github.com/LynnGuo666/PornHubApp) 的**安装源**，只包含源 JSON 与安装包，不含源码。

## 安装方式

### LiveContainer / SideStore / AltStore

1. 打开 LiveContainer（或 SideStore / AltStore）
2. 添加源：**Sources → +**，粘贴下面的地址
3. 在源里安装 **Pornhub**，用你自己的证书签名

```
https://raw.githubusercontent.com/LynnGuo666/PornHubApp-Source/main/source.json
```

安装后如需更新：刷新源即可看到新版本（`versions` 数组头部是最新版本）。

## 说明

- IPA 为**未签名**版本，安装时由 LiveContainer / AltStore / SideStore 用你的 Apple ID 证书重签。
- 内容为成人向，仅限成年人使用。
- 需要 iOS 16 或更高版本。
